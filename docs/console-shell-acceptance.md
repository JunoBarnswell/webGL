## Blocked 复现与解除条件

1. 全局监听器/DOM 测量：对当前 IAB 的 CDP capability 调用 `Memory.getDOMCounters`，返回 `This method is not supported through raw CDP.`。需要支持该命令及堆/CPU 采样的浏览器会话后，按相同场景、选择和 100 轮窗口操作采样；不能拿 Runtime 自有 6 个监听器代替全局结果。
2. 历史专业数据：在 `http://127.0.0.1:18080/editor/` 通过“文件 → 新建 / 打开 / 复制工程”查看本机工程，现有可用数据以油画展厅和模型导入编辑工程为主。补齐 U07–U12 对应原工程/资源/固定版本后，从“扩展”打开相同原设计器继续验收；无需切换旧工作空间或更改文档。
3. 中文 IME：在真实桌面浏览器中打开“命令面板 → 节点名称”，用系统中文输入法完成组合输入，同时在 Story Timeline/Viewport 间切换焦点核对快捷键。`.fill()` 或直接写入中文字符串不能证明系统 IME 通过。
