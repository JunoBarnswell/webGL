# 创作流程与界面依据

工作台围绕任务组织，共用一个主视口、文档、选择和撤销历史。顶栏保留工程、撤销、预览、保存、历史和发布；资源库按需打开；窄窗口的任务与属性抽屉互斥，优先保留视口面积。

| 任务 | 常用路径 | 精确操作 |
| --- | --- | --- |
| 场景搭建 | 导入 → 选择 → 变换/材质 | 层级、局部/世界、吸附、灯光、环境、碰撞 |
| 热点内容 | 点击表面放置 → 写标题和正文 → 预览 | 绑定对象、图文/解说引用、标记样式、内容版式 |
| 导览巡航 | 调整画面 → 记录视点 → 拖卡排序 → 停留 → 预览 | 位置/目标/FOV、移动时间、路径手柄、落地吸附、穿墙提示 |
| 事件交互 | 选对象 → 选模板 → 当/如果/就 | all/any、变量、分支、等待、重入策略、取消和执行记录 |
| 界面设计 | 改默认模板的内容和控件 | 自由/自动排列、尺寸、分组、对齐、吸附、多断点覆盖 |

基础选择与导航分离：默认选择；Alt+左拖环绕，中键平移，右键按住+WASD 飞行，Shift 拖动框选，F 聚焦。文字输入与二维画布不接收场景快捷键。聚焦排除编辑辅助物，骨骼模型采用当前姿态边界，并按相机方向、FOV 和窗口比例构图。

内容记录持有标题、正文、图片和音频引用；作品、热点、打开内容动作只引用内容 ID。界面设计器与 Player 共用 UiLayoutView、ContentCard、业务控件及样式，不分别维护预览版 UI。断点由实际容器宽度决定：1024px、768px；设计器显式使用相同断点属性。修改内容和布局分别形成命令，拖动仅在结束时提交一次。

巡航暂停保留进度，继续从当前位置推进，停止保留当前镜头，重播从首站开始。视点位置、朝向和 FOV 连续插值；展区和动作共用视点 ID。进入全景与导出全景为两个动作。

预览接管输入并显示完整 Player 界面。退出时取消运行规则、媒体、移动、镜头和输入捕获，恢复文档定义状态与编辑相机；预览不改变草稿修订。必需的错误提示、关闭内容和退出预览入口始终独立保留。

保存状态区区分云端已保存、本地未同步、失败和冲突。每个窗口独立保存 IndexedDB 事务；打开工程先检查恢复记录。409 保留原始基线和本地内容，用户可另存；不会自动把本地事务套用成较新云端修订。

配色采用深灰背景、清晰边框、浅色正文和薄荷绿操作强调，图标使用 Lucide。首次进入显示真实加载阶段、可取消任务和进入展厅界面；未就绪资源和未绑定动作保留错误并阻止发布。
