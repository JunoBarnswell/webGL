# 工作台产品设计基线

沿用 main 已确定的中文深色五区工作台，不生成概念效果图，不增加营销页面。

首次打开是管理员登录和真实工程列表。主界面由 57px 顶栏、Dockview 工作区和 29px 保存状态栏组成；左场景树 245px，右属性 310px，中间视口占主要面积，下方资源与交互区 255px。布局可停靠、缩放、保存及重置。小于 850px 时使用层级/视口/属性/资源/交互面板切换，维持可读控件尺寸。

背景 #14181e、面板 #1b2028、输入 #151a21、边框 #303844、正文 #dce3ed、弱文本 #8490a2、操作强调 #66d7b9。控件 11–12px，状态/辅助文字 9–10px，面板标题 12px，当前对象名称 15px。Inter / Noto Sans SC，系统中文字体兜底。使用一致的 Lucide 线性图标。

顶栏保留工程菜单、撤销重做、预览、保存、历史与发布。视口浮动工具条负责变换、坐标空间、吸附、聚焦和网格。属性面板按组件组织；材质默认修改时分离共享引用。资源按类型过滤，错误资源明确标记未就绪。交互区为事件列表、条件和有序动作，不假装为通用行为图。

发布只在草稿成功保存、Schema 和依赖全部通过后完成。错误必须显示服务返回的真实原因。预览接管视口输入；停止恢复文档状态。Player 保留业务控制与公开版本数据，不引用 Editor、Dockview、Zustand、Gizmo 或本地草稿。
